# Network Security Internship Project

## Project Title
Network Segmentation and Firewall-Based Security Implementation

## 1. Project Description

This project focuses on improving network security
through network segmentation and firewall configuration.

A virtual network environment will be created to
simulate a small company network.

The network will be divided into separate zones,
and firewall rules will control communication
between these zones.

## 2. Project Objectives

- Design a segmented network architecture.
- Configure a firewall using pfSense.
- Separate network zones.
- Control communication between network segments.
- Perform network scans using Nmap.
- Test allowed and blocked connections.
- Analyze the security results.

## 3. Tools and Technologies

- Oracle VirtualBox
- pfSense CE
- Kali Linux
- Ubuntu Server
- Nmap
- GitHub
